# 🕵️‍♂️ Поиск кратчайшего пути в ориентированном графе с помощью BFS

Данный проект реализует поиск кратчайшего пути между двумя заданными вершинами в ориентированном графе с использованием 
алгоритма поиска в ширину (BFS). Реализация выполнена с применением **Apache Spark** для обработки больших объемов данных.

---

## 📌 Задача

Найти кратчайший путь от вершины 12 к вершине 34 в ориентированном графе, представленном в виде списка рёбер 
(follower_id → user_id). Если существует несколько кратчайших путей — вывести первый найденный.
Алгоритм останавливается сразу после нахождения целевой вершины, что обеспечивает оптимизацию по времени выполнения.

---

## ⚠️ Обратите внимание

В коде стартовая и целевая вершины указаны как START_NODE = '34', TARGET_NODE = '12', то есть поиск идёт от 34 к 12, 
но результат выводится в обратном порядке (от 12 к 34), что соответствует условию задачи.

## 💡 Особенности реализации

Используется итеративный BFS через DataFrame API Spark. На каждом уровне хранится текущий узел и путь до него.
После каждого шага удаляются дубликаты node_id с помощью dropDuplicates, чтобы сохранить только первый достигнутый 
путь к каждой вершине (оптимизация производительности).
Алгоритм завершается сразу после обнаружения целевой вершины — без полного обхода уровня (гарантия кратчайшего пути).
В коде используется обратный поиск (от 34 к 12), результат перед выводом инвертируется.

---

## 📄 Формат входных данных

Файл twitter_sample.txt содержит строки в формате:
follower_id<TAB>user_id
Каждая строка представляет направленное ребро от follower_id к user_id.
